    Brand Guardrails

    Applied to every generation before you see it. Banned terms are replaced, hashtags are capped, and the disclaimer is appended — each adjustment is reported in Agent Logs.

    Local Relay

    The relay (python3 agent/nexus_relay.py) executes browser automation and publishing on this machine. It only accepts requests from Nexus and, if you set NEXUS_RELAY_TOKEN, requires the token below.

    Workspace Backup

    Settings, calendar, generation history, logs and the queue live in this browser only. Export them before clearing site data or switching machines.

    Read-only commands (navigate, snapshot, extract, screenshot, DevTools) run without permission. Click/type stay locked until you grant Browser Actions Permission below. Sessions persist between commands, so you can log in once and keep working.

    Browser Automation & DevTools Skill

    🔒 Read-only mode

    The agent can drive a real Chrome/Chromium session using Playwright or the raw Chrome DevTools Protocol — inspecting console errors, network timings and DOM like a developer. State-changing actions (click/type/post) are blocked until you grant permission below, and every command is written to an audit trail (logs/browser_audit.jsonl via agent/browser_automation.py).

    MCP Server — connect Nexus to any agent host

    Nexus ships an Model Context Protocol server (agent/nexus_mcp.py, zero dependencies) that exposes 11 tools — content generation, campaign planning, hashtag research, browser automation, DevTools inspection, video rendering and Telegram notify — to Google Antigravity, Claude Desktop, LM Studio (Hermes), Cursor, VS Code Copilot and remote-MCP clients via Grok. This is the extension point for future tools (Adobe After Effects, editing software, CRM…).

    Register in any MCP client (stdio)
    { "mcpServers": { "nexus": { "command": "python3", "args": ["PATH_TO_REPO/agent/nexus_mcp.py"] } } }

                                     How to get Instagram API credentials
                                    
      
                                        
    1. Go to developers.facebook.com and create a Meta App
      2. 
                                        
    2. Add Instagram Graph API product to your app
      3. 
                                        
    3. Go to Tools → Graph API Explorer
      4. 
                                        
    4. Generate a User Token with instagram_basic, instagram_content_publish permissions
      5. 
                                        
    5. Exchange for a Long-Lived Token (valid 60 days) using: 
      GET /oauth/access_token?grant_type=fb_exchange_token&client_id=APP_ID&client_secret=APP_SECRET&fb_exchange_token=SHORT_TOKEN
      6. 
                                        
    6. Get your Instagram Business Account ID from the Graph API Explorer: /me/accounts
      7. 
                                        
    7. Automation: Use the /<IG_ACCOUNT_ID>/media and /<IG_ACCOUNT_ID>/media_publish endpoints to post
      8.
