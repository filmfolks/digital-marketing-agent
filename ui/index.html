MCP Server — connect Nexus to any agent host

Nexus ships an Model Context Protocol server (agent/nexus_mcp.py, zero dependencies) that exposes 11 tools — content generation, campaign planning, hashtag research, browser automation, DevTools inspection, video rendering and Telegram notify — to Google Antigravity, Claude Desktop, LM Studio (Hermes), Cursor, VS Code Copilot and remote-MCP clients via Grok. This is the extension point for future tools (Adobe After Effects, editing software, CRM…).

Register in any MCP client (stdio)
{ "mcpServers": { "nexus": { "command": "python3", "args": ["PATH_TO_REPO/agent/nexus_mcp.py"] } } }

                                     How to get Instagram API credentials
                                    
    
                                        
  1. Go to developers.facebook.com and create a Meta App
    2. 
                                        
  2. Add Instagram Graph API product to your app
    3. 
                                        
  3. Go to Tools → Graph API Explorer
    4. 
                                        
  4. Generate a User Token with instagram_basic, instagram_content_publish permissions
    5. 
                                        
  5. Exchange for a Long-Lived Token (valid 60 days) using: 
    GET /oauth/access_token?grant_type=fb_exchange_token&client_id=APP_ID&client_secret=APP_SECRET&fb_exchange_token=SHORT_TOKEN
    6. 
                                        
  6. Get your Instagram Business Account ID from the Graph API Explorer: /me/accounts
    7. 
                                        
  7. Automation: Use the /<IG_ACCOUNT_ID>/media and /<IG_ACCOUNT_ID>/media_publish endpoints to post
    8.

                                     How to get Facebook Page API credentials
                                    
    
                                        
  1. Go to developers.facebook.com → Your App → Graph API Explorer
    2. 
                                        
  2. Select your App, then click Generate Access Token
    3. 
                                        
  3. Grant permissions: pages_read_engagement, pages_manage_posts
    4. 
                                        
  4. Call /me/accounts to get your Page ID and Page Access Token
    5. 
                                        
  5. Post automation: POST /<PAGE_ID>/feed with message and your access_token
    6.

                                     How to get YouTube Data API credentials
                                    
    
                                        
  1. Go to console.cloud.google.com → Create a project
    2. 
                                        
  2. Enable YouTube Data API v3
    3. 
                                        
  3. Create OAuth 2.0 credentials (Web App type)
    4. 
                                        
  4. Add https://developers.google.com/oauthplayground as redirect URI
    5. 
                                        
  5. Go to OAuth Playground, authorize scope: https://www.googleapis.com/auth/youtube.upload
    6. 
                                        
  6. Exchange authorization code for Refresh Token — store it here
    7. 
                                        
  7. Automation: POST to https://www.googleapis.com/upload/youtube/v3/videos with video file + metadata
    8.

                                     How to get Twitter/X API credentials
                                    
    
                                        
  1. Apply for a developer account at developer.x.com
    2. 
                                        
  2. Create a new App in the Developer Portal
    3. 
                                        
  3. Under Keys and Tokens, generate all 4 keys
    4. 
                                        
  4. Set App permissions to Read and Write
    5. 
                                        
  5. Automation (v2 API): POST https://api.twitter.com/2/tweets with Bearer Token header and {"text": "your tweet"} body
    6. 
                                        
  6. Note: Free tier allows 1,500 tweets/month. Basic plan ($100/mo) for higher limits.
    7.

                                     How to get LinkedIn API credentials
                                    
    
                                        
  1. Go to developer.linkedin.com → Create App

    3.

                                     How to get Blogger API credentials
                                    
    
                                        
  1. Go to console.cloud.google.com → Enable Blogger API v3
    2. 
                                        
  2. Create OAuth 2.0 credentials (same Google project as YouTube if desired)
    3. 
                                        
  3. Authorize with scope: https://www.googleapis.com/auth/blogger
    4. 
                                        
  4. Your Blog ID is in the URL: blogspot.com/blog/posts/<BLOG_ID>
    5. 
                                        
  5. Automation: POST https://www.googleapis.com/blogger/v3/blogs/<BLOG_ID>/posts
    6.

                                     How to set up Canva API access
                                    
    
                                        
  1. Go to canva.com/developers → Create a new Integration
    2. 
                                        
  2. Set Integration Type to Canva Connect API
    3. 
                                        
  3. Copy your Client ID and Client Secret
    4. 
                                        
  4. Click Authorize with Canva above — it will open Canva's OAuth page
    5. 
                                        
  5. After approval, Canva will redirect with an auth code — paste the resulting Access Token here
    6. 
                                        
  6. You can now list designs, create from templates, and export assets automatically
    7.
